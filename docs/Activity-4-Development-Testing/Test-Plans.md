# Test Plans (C.P5)

## Functional tests
- Login returns JWT for valid credentials.
- Unauthorized requests are rejected (401).
- Role mismatch is rejected (403).
- CRUD endpoints respond with expected status codes.

## Compatibility tests
- Chrome, Firefox, Safari checks for login/dashboard rendering.
- Mobile viewport check for responsive table layout.

## UX tests
- Patient registration flow in <= 3 actions.
- Patient full profile visible from patient table action.
